# dream兰 · 桃海 OPC 社区互动影片

10 页互动式影片网页，HTML 文案映射到视频中的展板，支持刷油漆显隐、项目展板缩放、正向翻页、返回倒放及局域网手机遥控。当前版本已移除摄像头手势功能。

## 电脑演示 + 手机遥控

1. 电脑安装 Python 3（Windows 中可使用 `py` 命令）。鼠标模式需要 Pillow，启动脚本会在缺少时安装；手动启动前可运行 `py -m pip install -r requirements.txt`。
2. 下载仓库并解压，双击 `启动手机遥控.cmd`，或在仓库目录执行：

   ```powershell
   py remote-server.py
   ```

3. 本地服务会自动打开电脑演示页。点击「手机遥控」查看手机配对地址，启动窗口也会打印完整地址。
4. 手机与电脑连接同一个 Wi-Fi，在手机浏览器打开本次生成的完整配对地址。
5. 手机端完整复用电脑演示界面，点击下一页、上一页、重播、章节按钮或案例展板即可控制电脑。视频、透视文字、刷字和案例展开状态随电脑同步，支持中途加入或断线重连。转场期间禁止重复翻页，上一页沿用倒放视频。
6. 保持服务窗口运行；按 Ctrl+C 结束。重新启动会更换配对链接。仅保留一个电脑演示窗口。

首次运行时，如 Windows 防火墙询问，请允许 Python 在当前专用网络通信。若手机无法访问，检查访客 Wi-Fi / 设备隔离 / VPN。手机声音按钮控制电脑声音；手机预览始终静音，避免双重音频。全屏需要在对应设备本地点击。

默认端口为 8769；若被占用，可运行 `py remote-server.py --port 8770`。

## 鼠标模式：操作内嵌网页

1. 将电脑演示浏览器放到前台。手机打开配对页，点击顶部「鼠标模式」，建议横屏。
2. 手机显示电脑的实际桌面，黄色标记是电脑真实鼠标位置。当前以 JPEG 连续取图，目标约 5 帧/秒，实际速度取决于设备和网络。
3. 「移动 / 点击」：手指滑动移动电脑鼠标，轻点执行左键点击。将鼠标移入展板可触发悬浮放大，然后点击里面的网页内容。
4. 「滚动」：在画面上上下滑动，滚动鼠标所在位置的网页，包括 iframe 内部。
5. 「拖动」：按住并滑动，可拖动滑块、网页模型等内容；松手释放鼠标。另有「右键」按钮。
6. 点击「返回演示」退出，或在电脑按 Esc 停止控制。手机切到后台、关闭页面或断线超过约 3 秒也会结束鼠标控制并释放拖动。

鼠标模式作用于 **Windows 整个真实桌面**，包括内嵌网页及新开的网页窗口；截图仅在内存中传送，不写入磁盘。保持演示窗口置前并关闭不希望展示的窗口。一次只允许一台手机控制。系统管理员权限窗口可能不接受输入。

该模式直接操作电脑，解决跨域 iframe 无法通过主网页转发内部点击的问题，不要求第三方网站修改代码。手机需保持配对页在前台，运行电脑需可见、未锁屏。

## 同步范围

电脑是唯一播放状态来源，手机先发指令，再跟随电脑确认的画面；约每 100ms 交换一次状态，并校准视频时间。实际延迟受局域网、设备与视频解码影响，并非屏幕逐帧投屏。手机前台显示时同步，返回前台后重新校准。

支持章节、翻页、重播、倒放、透视文字及刷字、案例展开/关闭、电脑声音开关。普通同步模式不会复制第三方 iframe 内部的滚动、点击或案例视频原生控件状态；要直接操作它们，请使用「鼠标模式」查看电脑实际画面并操作真实鼠标。全屏按钮只作用于点击按钮的设备。

## 普通网页 / 静态托管

`index.html` 为静态网站入口，`film.html` 为本地演示兼容入口。所有运行素材已随仓库提供，无需 Node.js 安装或构建。

可使用普通静态服务器预览：

```powershell
py -m http.server 8000
```

然后访问 `http://localhost:8000/`。可将本仓库根目录用于 GitHub Pages 等静态托管；仓库上传本身不代表已启用 Pages。

**局域网手机遥控需要运行 `remote-server.py`，并打开它生成的本地电脑链接。GitHub Pages 或其他公网静态地址不能直接承担此局域网服务。**

## 文件

- `film.js` / `film.css` / `film-data.js`：影片交互、样式、文案与透视坐标。
- `filmclip/` / `filmclip-reverse/`：正放与倒放视频。
- `assets/`：Logo、字体及笔刷遮罩，字体许可随文件提供。
- `film-stills/` / `case-media/`：静态参考帧与案例视频。
- `remote-server.py` / `remote-host.js` / `remote.html`：局域网服务、电脑客户端、手机遥控页。
- `desktop_control.py` / `desktop-remote.js`：Windows 桌面采集、真实鼠标输入与手机触控界面。
- `tests/test_desktop_control.py`：坐标、过期指令、会话和释放逻辑测试（`py -m unittest discover -s tests -v`）。

文案、品牌及视频素材未授予通用开源许可；第三方字体按各自附带许可使用。

实现参考：[Pillow ImageGrab](https://pillow.readthedocs.io/en/stable/reference/ImageGrab.html)、[Microsoft SendInput](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput)。
